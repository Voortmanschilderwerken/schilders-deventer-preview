# Voorbeeld van deventer-schilder.nl

Dit is een **voorbeeldversie (concept)** van de website voor Voortman Schilderwerken in Deventer. Hij is niet bedoeld om gevonden te worden: alle pagina's staan op noindex. Het offerteformulier verstuurt hier niets, dat werkt pas op de echte hosting.

Bekijk de site: https://voortmanschilderwerken.github.io/schilders-deventer-preview/
